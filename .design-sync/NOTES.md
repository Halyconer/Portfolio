# design-sync notes — adrianeddy portfolio

- This is an app repo, not a library: no `main`/`module` entry. The converter runs with `--entry ./.design-sync/support/entry.ts` — a hand-written barrel that re-exports every synced component (mirrors `componentSrcMap`). `pkg: "adrianeddy-portfolio"` matches the `name` field added to `package.json` for the sync.
- `pnpm build` (`tsc && vite build`) fails on the working tree whenever in-progress code trips `noUnusedLocals` (strict tsconfig). The sync's `buildCmd` uses `pnpm exec vite build` (no type-check) and copies the hashed `dist/assets/index-*.css` to the stable `cssEntry` path `.design-sync/.cache/app.css`.
- Styling is Tailwind v4 compiled at app build time: only utility classes actually used in `src/` exist in the compiled CSS. Authored previews must reuse the app's own classes (or inline styles) — novel utilities render unstyled.
- Fonts: Times New Roman by design (system font) — nothing to ship; `[FONT_MISSING]` should never fire.
- Router: Masthead, Projects, ProjectsIndex, CreativeHero, CreativeFooter render react-router links → `cfg.provider` wraps previews in `PreviewRouter` (MemoryRouter) from `.design-sync/support/preview-router.tsx`, exported through the barrel entry.
- LightDemo / Connect4Inline / Demos fetch the Pi backend (`apiFetch`); in previews the fetch fails and the components show their built-in offline fallback states — that is the expected preview render.
- Scope (user-confirmed 2026-07-10): editorial (12) + creative (6) components, all with authored previews. Excluded: ecommerce subapp, ErrorBoundary, pages, dev-roadtrip.
- Both `bun.lock` and `pnpm-lock.yaml` exist; pnpm-lock is the current one (newer in git) — install with `pnpm i --frozen-lockfile`.

## Wave learnings (folded 2026-07-10)

- Pi-backed components (Demos, LightDemo, Connect4Inline) settle into fully styled offline/idle fallbacks in preview (offline StatusDot, "AI READY" idle board) — correct renders, don't chase.
- ResumePDF's 8.5x11 sheet renders blank white (its PDF `/assets/AdrianEddy.pdf` doesn't ship); Hero's portrait frame likewise (`/assets/headshot.jpg`). Accepted, documented in conventions.md.
- Masthead `bare` variant intentionally renders an empty rule-only strip — looks empty on sheets, is the designed output.
- Photo components: omit `Photo.src` to get the intentional `--color-placeholder` hatched treatment — no broken-image frames. PhotoTile is `w-full`; wrap in inline maxWidth (~240-280px) to read as a column tile. PhotoSection renders 3 columns at card width; 6 photos = clean sheet.
- Demo cards preview best wrapped at ~520-560px maxWidth + `bg-paper`.
- `preview-rebuild.mjs` CONFIG_STALE gate is per-target: only components whose cfg.overrides changed since the stamped full build are blocked.

## Known render warns

- `[RENDER_THIN]`-adjacent: Masthead `Bare` cell and tall-section crops (Projects, ResumePDF at ~570px cell height) are sheet artifacts / by-design, not failures.
- Lightbox flags `thin`/`collapsed` (maxHeight 0): its root is a fixed-position overlay so the mount node has zero height. The render is complete (counter, close, chevrons, plate all present); `cardMode: single` + 900x600 viewport present it correctly.

## Re-sync risks

- `cssEntry` (.design-sync/.cache/app.css) is machine state regenerated by `buildCmd` — a re-sync that skips `buildCmd` after Tailwind class changes ships stale CSS. When in doubt, re-run buildCmd.
- Previews reuse only utility classes compiled into the app CSS; if a component/class is removed from `src/`, a previously good preview can silently lose styling — the render check + grades will catch majors, but eyeball sheets after big refactors.
- `.design-sync/support/entry.ts` mirrors `componentSrcMap` by hand — adding a component requires updating BOTH plus `package.json` name stays (`adrianeddy-portfolio`, added for the sync; a parent dir `~/Coding/package.json` otherwise hijacks package-root resolution).
- The `editorial-refactor` branch was the sync baseline (uncommitted working tree at sync time) — ProjectsIndex.tsx was untracked; if it's dropped or renamed on merge, update componentSrcMap + entry.ts.
